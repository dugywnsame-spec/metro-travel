지하철 타이핑 여행 · 온라인 버전 설치 가이드
================================================

이 폴더를 인터넷에 올리면 친구들이 구글 계정으로 로그인해서 같이 레이스하고 랭킹을 겨룰 수 있어.
처음 한 번만 설정하면 되고, 30분 정도 걸려. 비용은 들지 않아 (Firebase 무료 요금제 범위 안).

폴더에 들어 있는 파일
- index.html ........ 게임 본체
- online.js ......... 로그인 · 레이스 방 · 랭킹
- net-firebase.js ... Firebase 연결
- firebase-config.js  ← 2단계에서 여기만 고치면 돼
- firestore.rules ... 4단계에서 붙여넣을 보안 규칙


1단계. Firebase 프로젝트 만들기
  1) https://console.firebase.google.com 에 구글 계정으로 들어가.
  2) "프로젝트 만들기"를 누르고 이름을 정해 (예: metro-typing).
  3) Google 애널리틱스는 꺼도 돼. "프로젝트 만들기"로 마무리.

2단계. 웹 앱 등록하고 설정값 붙여넣기
  1) 프로젝트 첫 화면에서 웹 아이콘(</>)을 눌러 앱을 추가해. 닉네임은 아무거나.
  2) "Firebase 호스팅 설정"은 체크하지 않아도 돼.
  3) 화면에 나오는 firebaseConfig = { apiKey: ... } 부분을 복사해.
  4) 이 폴더의 firebase-config.js를 메모장으로 열고, 중괄호 { } 안을 복사한 내용으로 바꿔서 저장해.
     (apiKey 값은 공개되어도 괜찮은 값이야. 실제 보호는 4단계 보안 규칙이 해.)

3단계. 구글 로그인 켜기
  1) 왼쪽 메뉴 "빌드" > "Authentication" > "시작하기".
  2) "로그인 방법" 탭에서 "Google"을 골라 "사용 설정"을 켜고, 지원 이메일을 고른 뒤 저장.

4단계. 데이터베이스 만들고 보안 규칙 넣기
  1) 왼쪽 메뉴 "빌드" > "Firestore Database" > "데이터베이스 만들기".
  2) 위치는 asia-northeast3 (서울)을 추천. "프로덕션 모드"로 시작.
  3) 만들어지면 위쪽 "규칙" 탭을 열고, 원래 내용을 다 지운 다음 firestore.rules 파일 내용을 통째로 붙여넣고 "게시".
     → 이 규칙 덕분에 자기 기록만 고칠 수 있고, 방 설정은 방장만 바꿀 수 있어.

5단계. 인터넷에 올리기 (Netlify 추천, 무료)
  1) https://app.netlify.com 에 가입해. 구글 계정으로 가입할 수 있어.
     (가입 없이 올리면 사이트가 잠깐만 유지되니까 꼭 로그인한 상태로 올려.)
  2) https://app.netlify.com/drop 에 이 폴더를 통째로 끌어다 놓아.
  3) 잠시 뒤 https://○○○.netlify.app 같은 주소가 생겨. 사이트 설정에서 이름을 바꿀 수도 있어.

6단계. 사이트 주소를 Firebase에 등록
  1) Firebase 콘솔 > Authentication > "설정" 탭 > "승인된 도메인".
  2) "도메인 추가"를 눌러 5단계에서 받은 주소를 넣어 (https:// 빼고. 예: metro-typing.netlify.app).
     → 이걸 안 하면 구글 로그인 창에서 오류가 나.

7단계. 친구들과 놀기
  - 친구들에게 사이트 주소를 보내.
  - 각자 "구글로 로그인" → 닉네임 정하기.
  - 한 명이 "🏁 친구와 레이스" → "방 만들기" → 나온 5자리 코드를 친구에게 알려줘.
  - 친구는 "🏁 친구와 레이스" → 코드 입력 → "참가".
  - 방장이 "출발!"을 누르면 5초 뒤 모두 같은 역 이름으로 동시에 출발해.
  - "🏆 랭킹"에서 최고 타수, 레이스 승리 수, 난이도별 최고 점수를 볼 수 있어.


자주 생기는 문제
- 시작 화면에 "온라인 기능은 아직 설정 전" → firebase-config.js를 안 바꿨거나 저장이 안 된 거야.
- 로그인 창이 바로 닫히거나 unauthorized-domain 오류 → 6단계를 확인해.
- 랭킹이 안 뜨고 permission-denied → 4단계 규칙을 "게시"했는지 확인해.
- index.html을 더블클릭해서 열면 혼자 하기는 되지만 온라인 기능은 안 돼. 꼭 5단계처럼 인터넷에 올린 주소로 들어가.
- 파일을 고친 다음엔 Netlify 사이트 화면의 "Deploys"에 폴더를 다시 끌어다 놓으면 업데이트돼.

알아둘 점
- 점수는 각자의 브라우저에서 계산해서 올라가. 친구끼리 노는 용도라서 조작 방지는 기본 수준(말도 안 되는 값만 막음)이야.
- 무료 요금제로 하루에 쓰기 2만 번, 읽기 5만 번까지 돼. 친구 여럿이서 노는 데는 충분해.
